# Cutelaria Muniz — links oficiais

Página estática e responsiva em HTML e CSS, sem dependências ou etapa de build.

Para desenvolvimento, execute na raiz do repositório:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

No Cloudflare Pages, use o preset `None`, deixe o comando de build vazio e configure o diretório de saída como `.`. Mantenha o diretório raiz padrão.
